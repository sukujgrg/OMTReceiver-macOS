OMTReceiver

Receive video and audio from any compatible Open Media Transport sender. Allow local network access when macOS asks.

Choose a source

Click a live source thumbnail to open it fullscreen on the configured display. Arrow keys browse; Return or Space opens the selected source. Use File → New Receiver Window (⌘N) to receive another source independently. A built-in animated Test Pattern works without a sender and includes an alpha ramp.

If discovery is unavailable, choose File → Connect to Address (⌘O). Enter the sender’s actual address and TCP port, for example omt://192.168.1.20:6400. No fixed sender port is assumed.

Fullscreen and displays

Click a source thumbnail or press ⌃⌘F. Settings (⌘,) selects the default fullscreen display. Press Escape to return. Disconnecting the target display stops output and returns to the source browser.

Live previews

Previews are silent, use the sender’s reduced-resolution preview stream, and display up to 15 fps. Each browser receives up to 12 visible previews at once; scrolling retires offscreen previews. Fullscreen receives the original video format and audio separately. On another display, output can keep playing while you browse and click a different thumbnail. Escape stops fullscreen output.

Audio and formats

Each receiver has independent audio. Use ⇧⌘M or the speaker toolbar button to mute it. Receiving the same source twice can duplicate audio; mute the extra view. The status strip shows the source’s resolution, frame rate and scan format.

Automatic deinterlacing uses edge-directed field-rate interpolation on progressive displays. Preserve Fields (Weave) retains both fields and can show combing on progressive displays. Top Field First follows OMT’s convention; Bottom Field First is available for senders that require it. AppKit does not guarantee field-synchronized native interlaced scanout.

Alpha is composited over the chosen Black, Checkerboard or White background. Rec.601 and Rec.709 SDR, 8-bit and 16-bit decoded OMT pixel formats are supported; HDR is not tone-mapped.

Discovery server and recovery

Settings accepts an optional OMT Discovery Server URL, for example omt://server:6399. Apply and relaunch to change the SDK’s process-wide discovery configuration. Leave it empty for Bonjour discovery (_omt._tcp).

After signal loss the SDK reconnects automatically. View → Reconnect (⌘R) starts a fresh receiver. Disconnect (⇧⌘D) stops it. Ethernet is recommended for demanding streams.

Testing with eucaly

In eucaly, add an OMT Output in Settings → Outputs, give it a source name, enable it, and explicitly Start it or Show Slides. Select that source here. OMTReceiver works with other OMT senders as well.
